# Data Mining and Predictive Analytics — Imtiyaz Mohammed

Academic spreadsheets, datasets, and project material for predictive analytics.

## Topics represented in the files

- Toyota sales-price modeling and income time series
- K-nearest-neighbor classification using Hepatitis C data
- Wine and breast-cancer diagnosis datasets
- Book-club prediction and association analysis
- Market-basket, cosmetics, and course-topic association analysis
- Clustering with cereals and public-utilities datasets

See [coursework and project files](Data%20Mining%20and%20Predictive%20Analytics/). Open the workbooks in Excel or compatible software; some exercises use XLMiner or RapidMiner.

These are academic exercises. Model results depend on the dataset, split, and evaluation method used in each assignment and should be read in that context.
